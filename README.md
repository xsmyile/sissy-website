# sissy-website

The landing page for [Sissy](https://github.com/xsmyile/sissy), the macOS menu
bar app. One static page built with Astro; no backend.

```bash
npm install
npm run dev
```

`npm run build` writes the site to `dist/`. [AGENTS.md](AGENTS.md) has the
layout and the conventions.

The code is MIT. Sissy's name and artwork are not; `src/assets/brand/LICENSE.md`
says what that means.
